# Handoff

This file used to carry a full description of the project. That content now lives in two places,
so each audience has one source of truth rather than three copies that drift apart:

- **[README.md](README.md)** — the project: overview, features, architecture, API, deployment,
  security, and an explicit account of what is and is not implemented.
- **[CLAUDE.md](CLAUDE.md)** — working notes for agents: invariants, environment quirks, traps.

The old handoff was maintained by hand and stopped being true: it described a Stripe checkout that
had since been replaced by cash on delivery, and an AI key state that had changed twice. A document
that is confidently wrong costs more time than no document, so it is not maintained here any more.

Its full text remains in git history if you need it.
